THE DEDUCTION NOTEBOOK

How to play 📖

🎯 Objective

The computer secretly creates a code using the selected length. Your job is to discover the exact code. The code can be 3–7 digits. In Unique mode every digit is different. In Repetition mode duplicates are allowed within your chosen maximum.

🔁 A normal turn

Think → enter one complete guess → submit → read SAME and CORRECT → update your notes → choose the next experiment. You never need to click individual digit boxes.

🏁 Win

When CORRECT equals the code length, every position is correct and the code is cracked.

🔵 SAME

SAME counts how many digit occurrences from your guess exist somewhere in the secret. It does not reveal which digits.

Secret: 5831 · Guess: 1234 · SAME: 2

🟢 CORRECT

CORRECT counts digits that exist and are already in the exact position. CORRECT is included in SAME.

Secret: 5831 · Guess: 5839 · CORRECT: 3 · SAME: 3

🎲 Repetition feedback

When repetition is allowed, the game counts available occurrences only. A secret containing two 5s cannot give three matches for a guess containing three 5s.

✨ Unique

Every digit appears at most once. For a 4-digit game, 5831 is valid but 5531 is invalid.

🎲 Repetition

Your selected limit is a maximum, not a promise. “Up to 2×” means a digit may appear zero, one, or two times. It does not force a duplicate.

🎚️ Difficulty

Relaxed, Easy, Normal, Hard and Extreme change the challenge experience. The secret rules stay honest; difficulty should never reveal the answer.

⚡ Pressure

Set a time limit, an attempt limit, or both. The game ends when either limit is reached.

🧘 Focus

Focus Mode removes secondary navigation clutter and keeps your Constraint Map visible. It is a distraction-reduction mode, not a hint mode.

🚫 No-BS

No-BS removes optional coaching and decorative thinking panels. It leaves the core deduction surface.

🧠 The useful loop

Observe → Hypothesize → Test → Update → Repeat. A guess should answer a question, not merely hope to be right.

🔬 Controlled experiments

When possible, change one useful variable at a time. If you change everything, a new result can be difficult to interpret.

🚫 Hit-and-hope

Random guessing may eventually succeed, but it usually wastes information. A stronger guess tests a hypothesis, rearranges known digits, or eliminates a useful group of possibilities.

🧩 Constraint thinking

Separate what is impossible, what is possible, and what is merely likely. Your Constraint Map is a manual reasoning surface, not an automatic solver.

❓ Falsification

Ask: “What result would prove my current idea wrong?” This keeps you from protecting a favorite hypothesis.

🧪 Guess Lab

Guess Lab is a practice room for testing guesses and learning from feedback. It does not change your Records, Streaks, or normal game history.

🗺️ Constraint Map

Mark digits as unknown, possible, or ruled out. Under it, record a candidate for each position. These notes are yours; the game never fills them with the answer.

🧠 Coach

Coach is optional. Turn it off whenever you want a clean puzzle. When on, it asks thinking questions without telling you the answer.

📊 Post-game analysis

After a win, you can see attempts, time, repeated guesses, unique guesses, and an efficiency indicator. It is a reflection tool, not an intelligence score.

🤖 Robot vs Human

Both sides have a private secret using the same configuration. The turns alternate. The robot guesses your secret; you provide SAME/CORRECT if Auto Feedback is off. Then you guess the robot's secret; the robot automatically returns SAME/CORRECT.

⚙️ Auto Feedback

When Auto Feedback is on, the game calculates the robot's feedback from your secret automatically. You do not have to enter SAME/CORRECT manually.

🏆 Battle win

The first side to reach CORRECT equal to the code length wins. The robot's secret mask always matches the selected length.
